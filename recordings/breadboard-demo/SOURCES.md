# Virtual breadboard demo — frame sources

No physical breadboard was available, so this recording is assembled from freely
licensed Wikimedia Commons media, resized to ≤ 800 px and renamed to the
`<seq>-<ts>.jpg` layout `pnpm demo:replay` expects (2 fps). Attribution is
required by CC BY-SA; keep this file next to the frames.

`control.jsonl` walks `/scan?domain=breadboard → scan 6 s → /builds →
/guide/blink → next → where → check → next`.
